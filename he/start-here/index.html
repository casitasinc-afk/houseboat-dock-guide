בלי מכונית? לחץ כאן

הגעה ומחנה

חניה חינם דורשת את הצעדים הבאים:

  1. שלח לנו את מספר לוחית המכונית (למשל ABA3235) ללא פסיקה, דרך צ'אט Airbnb. תעשה את זה באופן אידיאלי עכשיו. זה יגדיל את הסיכוי שלך לחנות קרוב לסירות הבית.
  2. צפו VIDEO זה עם אפשרויות חניה 🙂
  3. הקש על חניה A, B או C כדי לראות אפשרויות החנייה.

חניה A. 80 מטרים מהסירות. השתמש במקומות ללא לוגו של החברה.

חניה B 60 מטר מהסירות הבית. מקומות ליד קיר הבטון.

חניון C (8 מקומות הקרובים ביותר) 50 מטרים מהסירות. תשאיר את כל המכונית מאחורי הקו הלבן!

ואז ללכת לבית הסירות הליכה דרך חניה C.

חשוב: מקומות חניה מוגבלים ל-12 מכוניות. זה יכול להיות שכל המקומות תפוסים והחניה צריכה להיעשות מחוץ לנמל. זה נדיר יחסית.

צא מהנמל באותו כיוון, צפונה. שער היציאה נפתח אוטומטית.

חשוב!

ברגע שתגיע, שלח לנו תמונה של המכוניות החונות עם מספר לוחיות באמצעות צ'אט Airbnb. חניה במקום הלא נכון עולה 10 יורו לשעה, דמי משאית גררה הם 250 יורו! אנא הימנע מבעיות

רישום כניסה

בדוק את שם הסירה והקוד של תיבת המנעול שלך מדריך ההגעה של Airbnb. צעד ל מקום זה. מצא את הסירה שלך על המפה הזאת פתח את תיבת המנעול והכנס. סגור את תיבת המנעול ותערבב את המספרים. זרוק את המזוודות שלך וקח דקה לבדוק את הסירה

לדווח מיד על כל נזק או בעיה.

הליכה לנמל

השתמש בשער הכחול הזה (מיקום במפות גוגל). קוד קופסת המנעול 3570 להיכנס. תחזיר את המפתח, סגור את הקופסא ותערבב את המספרים. תמיד תנעל את הדלת, אחרי שאתה נכנס או יוצא.
