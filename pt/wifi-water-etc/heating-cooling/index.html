Aquecimento e Refrigeração

O controle remoto tem um botão "MODE".

Para aquecer a sala, pressione MODE até ver o símbolo HEAT ou um ícone SUN. Pode demorar alguns minutos para a unidade começar a aquecer.

Para arrefecer a sala, pressione MODE até ver o sinal COOL ou um ícone SNOW. Pode demorar alguns minutos para a unidade começar a aquecer.

Os outros modos não são geralmente utilizados.

Os ícones remoto para A / C pode diferir um pouco
