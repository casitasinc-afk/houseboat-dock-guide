Pemanasan & Pendinginan

Remote control memiliki tombol "MODE".

Untuk memanaskan ruangan, tekan MODE sampai Anda melihat tanda HEAT atau ikon SUN. Mungkin butuh beberapa menit untuk unit mulai memanaskan.

Untuk mendinginkan ruangan, tekan MODE sampai Anda melihat tanda COOL atau ikon SNOW. Mungkin butuh beberapa menit untuk unit mulai memanaskan.

Modus lain biasanya tidak digunakan.
