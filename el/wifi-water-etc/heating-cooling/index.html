Θέρμανση και ψύξη

Το τηλεχειριστήριο έχει ένα κουμπί "MODE".

Για να ζεστάνετε το δωμάτιο, πατήστε MΟDE μέχρι να δείτε το σύμβολο HEAT ή ένα εικονίδιο SUN. Μπορεί να χρειαστούν αρκετά λεπτά για να αρχίσει η θέρμανση.

Για να ψύξετε το δωμάτιο, πατήστε το πλήκτρο MODE μέχρι να δείτε το σύμβολο COOL ή ένα εικονίδιο SNOW. Μπορεί να χρειαστούν αρκετά λεπτά για να αρχίσει η θέρμανση.

Οι άλλοι τρόποι δεν χρησιμοποιούνται συνήθως.

Τα εικονίδια του τηλεχειριστή για A / C μπορεί να διαφέρουν λίγο
