Calentamiento y refrigeración

El mando a distancia tiene un botón "MODE".

Para calentar la habitación, presione MODE hasta que vea el símbolo de calor o un icono SUN. Puede tomar varios minutos para que la unidad comience a calentar.

Para enfriar la habitación, presione MODE hasta que vea el signo COOL o un icono SNOW. Puede tomar varios minutos para que la unidad comience a calentar.

En general, no se usan los otros modos.

Los iconos remotos para el aire acondicionado pueden diferir un poco
