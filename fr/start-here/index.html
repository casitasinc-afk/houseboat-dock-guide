ARRIVÉE ET STATIONNEMENT

Le stationnement gratuit exige strictement ces étapes:

  1. Envoyez-nous les numéros de plaque d'immatriculation (par exemple ABA3235) sans trait d'union, via chat Airbnb. Faites-le idéalement maintenant. Vous aurez ainsi plus de chances de vous garer près des canots.
  2. Regardez CE VIDEO avec les options de stationnement 🙂
  3. Appuyez sur A, B ou C pour voir les options de stationnement.

Parking A. À 80 mètres des voiliers. Utilisez les places SANS logos d'entreprise.

Parking B à 60 mètres des voiliers. Places le long du mur de béton.

Parking C (les 8 endroits les plus proches) à 50 mètres des cabines. Gardez toute la voiture derrière la ligne blanche !

Puis marcher jusqu' aux bateaux-maison en passant par le parking C.

IL EST IMPORTANT: Les places de stationnement sont limitées à 12 voitures. Il se peut que TOUTES les places soient occupées et le stationnement doit être fait à l'extérieur du port. C'est relativement rare.

Sortez du port dans la même direction, vers le nord. La porte de sortie s'ouvre automatiquement.

C'EST TRÈS IMPORTANT !

Une fois arrivé, envoyez-nous une photo des voitures garées avec les plaques d'immatriculation via chat Airbnb. Le stationnement au mauvais endroit coûte 10 €/heure, les frais de remorquage 250 €! VEUILLEZ ÉVITER LES PROBLÈMES

ENREGISTREMENT

Vérifiez le nom et le code de votre bateau-maison dans le guide d'arrivée Airbnb. Marchez jusqu'à ce lieu. Localisez votre bateau-maison sur cette carte (localisation des bateaux-maison). Ouvrez le coffre et entrez. Fermez la boîte et mélangez les numéros. Posez vos bagages et prenez une minute pour vérifier la maison-bateau

Signalez immédiatement tout dommage ou problème.

JE MARCHE VERS LE PORT

Utilisez cette porte bleue (localisation sur Google Maps). Code 3570 pour entrer. Remettez la clé, fermez le coffre et mélangez les numéros. Toujours verrouiller la porte, après être entré ou sorti.

Lisez "Taxi, métro, tramway, bus"
