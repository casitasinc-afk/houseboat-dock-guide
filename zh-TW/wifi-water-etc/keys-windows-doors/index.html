Keys

Keys: We provide ONE set of keys. Additional keys must be asked for before the stay. Lost keys will be charged 35 EUR per set. Please, be careful!

Windows and doors

work this way:

Handle UP - window upper edge comes out "Vent mode". Do not turn the handle when open.

Handle HORIZONTAL - Door mode, move handle only when you push window with your hand to closed position. Please do not touch the glass.

Handle DOWN - Locked. Put the handle in this position ONLY when the window is closed, so it is locked.

When leaving the houseboat please close the windows and doors. Keep any cushions indoors.

MOST ENTRANCE DOORS are solid wood. This is a natural material that changes shape and size with weather, moisture, heat or cold. The door might require to be raised slightly from the handle, in order to lock/unlock with the key, or to push the door for it to latch closed.
