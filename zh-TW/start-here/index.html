  2. 我們希望這些車站能使用這種方式 🙂 這段影片
  3. 按 A,B 或 C 停車位查看停車選擇.

停車場A距離船屋80米. 請使用沒有公司標誌的車位。

停車場B距離屋船60米. 靠混凝土牆的車位。

停車場C (最近的8個位置) 距離遊艇50米. 保持整個車輛在白線後面!

然後走到船屋, 穿過停車場C.

重要的是:停車位限於12輛. 也許所有車位都被佔用, 這是相對罕見的.
